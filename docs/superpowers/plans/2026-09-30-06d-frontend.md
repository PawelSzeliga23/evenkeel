# Plan 6d — frontend: wycena „do wypłaty” i drobiazgi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The web app shows the payout value (market value − exit costs) on the Pulpit, in Pozycje and in the
position detail, lets the owner set a manual spread per instrument, and fixes the chosen small issues.

**Architecture:** The backend plan (`2026-09-30-06d-backend.md`, executed first on the same branch) already returns
`SummaryOut.value_pln` as the payout value with `market_value_pln` / `exit_cost_pln`, and positions with
`exit_fx_pln`, `exit_spread_pln`, `exit_cost_pln`, `payout_pln`, `spread_pct`. This plan updates types and fixtures,
then the screens, then the small fixes. One tiny API addition (`price_currency` in history items) is in Task 5.

**Tech Stack:** React 19 + TypeScript + Vite, TanStack Query, React Router, Vitest + Testing Library (in `web/`:
`npx vitest run <file>`; type check `npx tsc -b`), CSS modules. API tests: `docker compose run --rm api pytest`.

**Spec:** `docs/superpowers/specs/2026-09-30-06d-payout-valuation-design.md` (§2 and §3).

## Global Constraints

- Polish UI copy exactly as written in this plan; amounts through `formatMoney` / `<Money>` (NBSP before „zł”,
  real minus `−`). Testing Library normalizes NBSP to a plain space in matchers: tests use `T = " "` for NBSP and
  `M = "−"` for the minus, like the existing tests.
- The Pulpit line „Wartość rynkowa X · koszty wyjścia −Y” and the detail section „Do wypłaty” show only when the
  exit cost is greater than zero.
- Positions list and group totals use `payout_pln`; `value_pln` stays the market value in the API.
- Decimals stay strings (`Money`); never parse money through floats except for chart geometry (existing).
- Commit messages in English, conventional style, ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A portfolio with only bonds and savings (exit cost `"0.00"`) must show no „koszty wyjścia” line anywhere.
- The spread field: an empty field saves `null`; „0,1” (comma) saves `"0.1"`; „6” shows an error without a request.
- Switching the account on the Pulpit must keep the old numbers visible until the new ones arrive (no skeleton).
- Logging out while the API is down must still end the session in every open tab.
- The history price of a transaction without an instrument currency shows no currency code, not „null”.

```tsx
function SpreadForm({ instrument }: { instrument: Instrument }) {
  const queryClient = useQueryClient();
  const [text, setText] = useState(instrument.spread_pct ? formatDecimal(instrument.spread_pct, 4) : "");
  const [error, setError] = useState<string | null>(null);
  const save = useMutation({
    mutationFn: (value: string | null) => api.updateInstrument(instrument.id, { spread_pct: value }),
    onSuccess: async () => {
      setError(null);
      await Promise.all([
        queryClient.invalidateQueries({ queryKey: keys.instruments }),
        queryClient.invalidateQueries({ queryKey: keys.portfolio }),
      ]);
    },
    onError: (err) => setError(errorMessage(err)),
  });

  function submit(event: FormEvent) {
    event.preventDefault();
    if (!text.trim()) {
      save.mutate(null);
      return;
    }
    const value = parseAmount(text, 4);
    if (value === null || Number(value) > 5) {
      setError(SPREAD_RANGE);
      return;
    }
    save.mutate(value);
  }

  return (
    <form className={styles.sourceEdit} onSubmit={submit} noValidate>
      <Field id={`spread-${instrument.id}`} label="Spread (%)" error={error ?? undefined}
        hint="Połowa różnicy między ceną kupna a sprzedaży. Zostaw puste dla płynnych ETF-ów.">
        <input id={`spread-${instrument.id}`} inputMode="decimal" value={text}
          onChange={(e) => { setText(e.target.value); setError(null); save.reset(); }} aria-invalid={Boolean(error)} />
      </Field>
      {save.isSuccess && <p role="status">{SPREAD_SAVED}</p>}
      <div className={forms.actions}>
        <button type="submit" className={ui.primaryButton} disabled={save.isPending}>Zapisz spread</button>
      </div>
    </form>
  );
}
```

and in `Source`, inside `{open && (...)}`, wrap the existing `<form>` and the new form in a fragment:

3. In the provider, a listener effect:

```tsx
  useEffect(() => {

    const channel = new BroadcastChannel(SESSION_CHANNEL);
    channel.onmessage = (event) => {
      if (event.data !== "signed-out") return;
      setAccessToken(null);
      queryClient.clear();
      setState({ status: "anonymous", expired: false });
    };
    return () => channel.close();
  }, [queryClient]);
```

```tsx
  const signOut = useCallback(async () => {

    }
    setAccessToken(null);
    queryClient.clear();
    announceSignOut();
    setState({ status: "anonymous", expired: false, offlineLogout: offline });
  }, [queryClient]);
```
