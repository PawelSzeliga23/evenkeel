# Plan 8b — Motyw jasny i ciemny — Implementation Plan

> **For agentic workers:** executed inline (superpowers:executing-plans) on branch `feature/theme`. The owner waived
> the spec and plan reviews (2026-10-04); ask only before merging.

**Goal:** a hand-switched light theme („Ciepły papier”) next to the existing dark one, saved per device, with every
colour of the app living in two files: `web/src/styles/theme.css` (UI) and `web/src/styles/chart-colors.css` (charts).

**Spec:** `docs/superpowers/specs/2026-10-04-08b-theme-design.md` — the colour tables there are the source of truth.

**Tech:** CSS custom properties switched by `html[data-theme="light"]`; `color-mix()` for computed heat shades;
React context like `PrivacyProvider`; an inline boot script in `index.html`. No API change, no migration.

## Global constraints

- The dark theme must look exactly as today: every dark value in the two files equals today's literal.
- After Task 2 no `.ts/.tsx/.css` file under `web/src` (except the two colour files, tests and `test/fixtures.ts`)
  contains a colour hex or `rgb(`/`rgba(`; a guard test enforces it.
- Commands: `cd web && npx vitest run`, `npx tsc -b` (or `npm run typecheck` if defined), e2e `npm run e2e`.

### Task 3: ThemeProvider and the boot script

**Files:** create `web/src/settings/theme.tsx`, `web/src/settings/theme.test.tsx`; modify `web/index.html`,
`web/src/providers.tsx` (or wherever `PrivacyProvider` is mounted).

- [ ] `theme.tsx`:
  ```tsx
  export type Theme = "dark" | "light";
  export const THEME_KEY = "evenkeel.theme";
  export const THEME_COLORS: Record<Theme, string> = { dark: "#0E1116", light: "#F6F3EC" };
  export function storedTheme(): Theme { try { return localStorage.getItem(THEME_KEY) === "light" ? "light" : "dark"; } catch { return "dark"; } }
  export function applyTheme(theme: Theme): void {
    const root = document.documentElement;
    if (theme === "light") root.dataset.theme = "light"; else delete root.dataset.theme;
    document.querySelector('meta[name="theme-color"]')?.setAttribute("content", THEME_COLORS[theme]);
    document.querySelector('meta[name="color-scheme"]')?.setAttribute("content", theme);
  }
  ```
  `ThemeProvider` holds `useState(storedTheme)`, calls `applyTheme` in a layout effect, and its setter stores
  (`try/catch`) and applies. `useTheme()` returns `[theme, setTheme]`.
  `THEME_COLORS` duplicates `--night` for the browser meta; the colour guard skips it via a
  `// colour-guard: allow` line marker (the guard ignores lines carrying it) — document that in both places.
- [ ] `index.html`: before the module script,
  `<script>try{if(localStorage.getItem("evenkeel.theme")==="light"){document.documentElement.dataset.theme="light";document.querySelector('meta[name="theme-color"]').content="#F6F3EC";document.querySelector('meta[name="color-scheme"]').content="light"}}catch(e){}</script>`.
- [ ] Mount `ThemeProvider` next to `PrivacyProvider`.
- [ ] Tests: default dark (no attribute, meta `#0E1116`); stored light applies on mount; setter writes storage, sets
  attribute and meta; throwing `localStorage` → dark and no crash.
- [ ] Commit `feat(web): theme provider, per-device storage and boot script without a flash`.
