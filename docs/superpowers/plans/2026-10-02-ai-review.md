# Claude portfolio review (copy-paste) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app builds one Markdown file (instructions for Claude plus the portfolio's data and measures), the owner pastes it into claude.ai, pastes Claude's Markdown answer back, and reads saved reviews rendered like a README.

**Architecture:** A new API module `app/reviews`:
- `prompt.py` holds the instruction text and the nine expected headings;
- `package.py` renders the data by calling the existing services (summary, positions, analytics, history, limits, closed, scenarios, bonds) and formatting tables in Polish;
- `router.py` serves the package and CRUD for a new `ai_reviews` table.

The web gets `/analiza/przeglad` (prepare, paste, list), `/analiza/przeglad/:id` (read, delete) and a card on Analiza. Markdown is rendered with `react-markdown` + `remark-gfm`, with no raw HTML.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, pytest; React 19, TanStack Query, react-markdown 10, remark-gfm 4, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-02-ai-review-design.md` (§1 navigation is already done and merged).

## Global Constraints

- The headings, verbatim and in this order:
  1. `## Ocena ogólna`
  2. `## Mocne strony`
  3. `## Ryzyka`
  4. `## Rynek`
  5. `## Twoje instrumenty`
  6. `## Pomysły do rozważenia`
  7. `## Propozycje`
  8. `## Pytania do przemyślenia`
  9. `## Źródła`
- The answer comes in a ````` ````markdown ````` block (four backticks). The server strips fences of 3 or 4 backticks.
- **Never in the package:** `external_account_number`, the e-mail, database ids, XTB position ids.
- Amounts are written as „1 234,56 zł” (NBSP as the thousands separator, comma for decimals) and percentages as „12,3 %”.
- `content` is at most 200 000 characters. An empty one gives 422 `validation_error`; one that is too long gives 422 `review_too_long` with „Przegląd jest za długi (najwyżej 200 000 znaków).”
- Owner rules:
  - XTB-first numbers: the package uses the same services as the screens;
  - the risks list in spec §6 is low priority; keep only no-HTML rendering and the table scroll box.
- Commands: `docker compose run --rm api pytest -q`; `cd web && npx vitest run && npx tsc --noEmit`; `cd web && npx playwright test`.

## Review Focus

1. **The package for chosen accounts:** it contains only those accounts' positions, and the totals equal `/api/portfolio/summary` for the same filter. Pinned in Task 1.
2. **A pasted answer with prose before or after the fence:** the fence is still stripped and the sections counted. Pinned in Task 2.
3. **Raw HTML in a pasted answer** is shown as text and never executed. Pinned in Task 4.

### Task 2: Saved reviews (API)

**Interfaces — Produces:**
- `clean(text) -> str`: strips a surrounding fence of 3 or 4 backticks (optionally tagged `markdown`) and any prose outside the first such fence. Without a fence, the trimmed text.
- `count_sections(text) -> int`: the number of SECTIONS present as level-2 headings. Matching is case-insensitive and ignores leading emoji or punctuation.
- `ReviewIn {content: str (1..200 000 after clean), account_ids: list[int] = []}`.
- `ReviewOut {id, created_at, account_label, sections, content}`; `ReviewListItem` is the same without `content`.
- Routes: `GET /api/reviews`, `POST /api/reviews` (201), `GET /api/reviews/{id}`, `DELETE /api/reviews/{id}` (204). Another user's review is 404. `account_label` is „Cały portfel” or the chosen account names joined with „, ”.

**Behaviour:**
- `Markdown` renders with `remarkPlugins={[remarkGfm]}` and no `rehype-raw`, so HTML stays text. The `components` mapping does three things:
  - `h2` gets a coloured marker. The colour comes from the section title by normalized match; unknown titles get dim;

  - `table` is wrapped in `<div className={styles.tableScroll}>` with `overflow-x: auto`.
- Colours: Ocena ogólna and Propozycje `var(--amber)`, Mocne strony `var(--gain)`, Ryzyka `var(--loss)`, Rynek and Twoje instrumenty `#3987e5`, Pomysły `#9085e9`, Pytania and Źródła `var(--dim)`.
